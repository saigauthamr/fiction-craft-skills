# Viewpoint-Filtered Description

Describe a place the way this character, in this mood, would see it. A neutral author's inventory of the room does no work. A filtered description is characterization and foreshadowing at the same time, so scene-setting is never wasted effort.

## Method

1. **Pull the reader in first.** Start with the characters launching into a problem, or with dialogue, then set the scene around it.
2. **Anchor the viewpoint early.** Make the viewpoint character's name the first one in the scene or chapter, since readers scan for it. If another name must come first, give the action verb to the viewpoint character or have them watch that person. A beginner's rule of thumb that experienced writers can break.
3. **Describe through perception.** The same mist, or the same ticking clock, is playful to one character and ominous to another. A reader should be able to tell whose head they are in from the description alone.
4. **Use a single line in the character's voice.** One sharp line, such as a woman so tough she could chew steel and spit nails, does more than three paragraphs.
5. **Re-set the scene in every chapter,** even in the same place, with the character noticing something different.
6. **Remind through interaction.** When characters are talking at length, have them lean on a wall, slam a table, or look across the setting. A single line about a recurring feature is enough, and it pulls the dialogue back to the concrete.

## Checks

- `worldbuilding.filtered.01` Cover the name tags. Can you tell from the description who is looking and how they feel?
- `worldbuilding.filtered.02` Is each description a catalog of what exists, or a record of what this person notices?
- `worldbuilding.filtered.03` Across chapters in one location, does each opening notice something new?
- `worldbuilding.filtered.04` Do recurring features get a full description each time, where a line would do?

## Cautions and exceptions

- There is no rule for how often to describe. Add a reminder when the reader might lose the setting.
- A story set almost entirely in one room can work very well, as long as the room changes through the character's changing state. Making repeated description fresh is a skill to practice, for example by describing a two-person scene in an empty room through shifting mood.
- If the worldbuilding matters to the plot but not to this character, signal its weight through the narrative, cut to a viewpoint that cares, or tie it to something the character does care about.
- Use `worldbuilding-pyramid-of-abstraction` to keep the description concrete, and `worldbuilding-learning-curve-and-exposition` for how much to reveal.
