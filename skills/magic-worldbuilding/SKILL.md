# Magic Worldbuilding

Magic and worldbuilding are tools for the story, and the skills here keep them in that role. Load only the child you need.

## Children

**Magic**
- `magic-hard-and-soft`: how rule-bound or mysterious a magic system should be.
- `magic-internal-and-external-logic`: whether readers can predict a system from inside it, and why real science does not make it hard.
- `magic-zeroth-law`: choosing the exciting option over the merely plausible one.
- `magic-first-law`: when magic can solve the climax without feeling like a cheat.
- `magic-second-law`: costs and limits, so power does not collapse the tension.
- `magic-third-law`: going deeper into what you have instead of adding more.

**Building the world**
- `worldbuilding-idea-intersection`: turning a pile of ideas into a book by combining setting, character, and plot ideas.
- `worldbuilding-three-part-split`: sorting world notes into physical setting, cultural setting, and magic.
- `worldbuilding-worldbuilders-disease`: building without ever starting the book.
- `worldbuilding-hollow-iceberg`: how much of the world to build deeply and how much to only suggest.

**Showing the world on the page**
- `worldbuilding-pyramid-of-abstraction`: anchoring scenes and explanations in concrete detail.
- `worldbuilding-naming`: naming people, places, and things in an invented world.
- `worldbuilding-learning-curve-and-exposition`: how much a reader can take in, and in what order.
- `worldbuilding-gorilla-in-the-phone-booth`: when a new element steals attention from the main thread.
- `worldbuilding-viewpoint-filtered-description`: describing setting through the viewpoint character.

## Which child for which problem

| The writer says | Load |
| --- | --- |
| "My magic feels random" / "is this hard or soft magic?" | `magic-hard-and-soft`, `magic-internal-and-external-logic` |
| "The magic solves the ending and it feels like a cheat" | `magic-first-law` |
| "My hero is overpowered" / "what should the magic cost?" | `magic-second-law` |
| "My world keeps growing and feels shallow" | `magic-third-law`, `worldbuilding-hollow-iceberg` |
| "Plausible or cool?" | `magic-zeroth-law` |
| "I have ideas but no book" | `worldbuilding-idea-intersection` |
| "Where do I start building a world?" | `worldbuilding-three-part-split` |
| "I've been building for years and haven't started" | `worldbuilding-worldbuilders-disease` |
| "It reads like an encyclopedia" | `worldbuilding-hollow-iceberg`, `worldbuilding-learning-curve-and-exposition` |
| "Talking heads in a void" / "info dump" | `worldbuilding-pyramid-of-abstraction` |
| "I need names for a culture" | `worldbuilding-naming` |
| "A late reveal steals the show" | `worldbuilding-gorilla-in-the-phone-booth` |
| "My scene-setting reads like a brochure" | `worldbuilding-viewpoint-filtered-description` |
