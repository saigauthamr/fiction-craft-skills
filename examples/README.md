# Examples

Short before-and-after cases that show what the guidance changes. Read them as **single illustrative samples**, not benchmarks: each is one run on one model from one fictional project, judged by one reader. They show the kind of difference to expect, not how often you will see it.

| Example | What it shows |
| --- | --- |
| [Dialogue, before and after](dialogue-before-after.md) | The same confrontation scene drafted with and without the dialogue guidance |
| [Narration, before and after](narration-before-after.md) | The same solitary scene drafted with and without the narration guidance |
| [Learning from your edits](learning-from-edits.md) | What `story-edits` reads in a writer's changes, and the lessons it saves |

All stories, characters, and prose here are invented for this library.
