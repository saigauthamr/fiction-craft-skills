# Dialogue pair

The same confrontation chapter (`beats.md`), drafted twice by the same model from the same project: once with `story-draft` as it was, and once with its new sections "How people talk" and "Leave the meaning to the reader". The two drafts are labelled A and B in a random order. The key and the rubric counts are kept out of this folder until the owner has read both blind.

## Result

The owner read both blind and preferred **B**: "more natural and spread out and not the same size. There is no obvious AI 'it is X not Y' etc." B was the draft written with the new guidance, so the guidance ships.

| Rubric count | A (before) | B (with guidance) |
| --- | --- | --- |
| Words | 1,306 | 1,198 |
| Share of words in dialogue | 34% | 46% |
| Lines of dialogue | 63 | 67 |
| Speeches over 60 words | 0 | 0 |
| Lines that break off | 0 | 2 |
| Consecutive lines sharing a three-word phrase | 1 | 3 |

The last count disagrees with the read. The counter is crude (any shared three-word phrase counts, including deliberate repetition), so it is a guard, not a verdict. One draft per version: a single sample.
